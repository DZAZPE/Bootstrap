Funcionalidades

Seis elementos para diseñar una experiencia de revisión de textos. Estas tarjetas describen la propuesta del producto.

01

Introducir texto

Un área de escritura permite preparar el contenido que se desea revisar.

Ver detalle de Introducir texto
02

Adjuntar documentos

Un campo de archivo representa la carga de un trabajo académico.

Ver detalle de Adjuntar documentos
03

Consultar coincidencias

Un informe de ejemplo destaca los fragmentos que requieren revisión.

Ver detalle de Consultar coincidencias
04

Comparar fuentes

La comparación visual ayuda a localizar el origen de un fragmento.

Ver detalle de Comparar fuentes
05

Interpretar resultados

Las barras y etiquetas organizan los datos del informe.

Ver detalle de Interpretar resultados
06

Revisar las citas

La revisión final comprueba cómo se atribuyen las ideas utilizadas.

Ver detalle de Revisar las citas
